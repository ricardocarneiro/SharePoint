# Job Tracker (React + Supabase)

App com autenticação Supabase e páginas:
- `/login`
- `/signup`
- `/dashboard` (rota protegida)
- `/clients`
- `/projects`

UI com Tailwind CSS e componentes estilo shadcn/ui (botão base e layout clean).

## 1) Pré-requisitos
- Node.js 18+
- Projeto Supabase

## 2) Instalação
```bash
npm install
```

## 3) Variáveis de ambiente
Crie `.env`:
```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

## 4) Banco de dados (Supabase SQL)
Execute no SQL Editor:
```sql
create table if not exists public.clients (
  id bigint generated by default as identity primary key,
  name text not null,
  created_at timestamp with time zone default now()
);

create table if not exists public.projects (
  id bigint generated by default as identity primary key,
  name text not null,
  created_at timestamp with time zone default now()
);

alter table public.clients enable row level security;
alter table public.projects enable row level security;

create policy "Allow authenticated read/write clients"
on public.clients for all
using (auth.role() = 'authenticated')
with check (auth.role() = 'authenticated');

create policy "Allow authenticated read/write projects"
on public.projects for all
using (auth.role() = 'authenticated')
with check (auth.role() = 'authenticated');
```

## 5) Auth Supabase
No painel Supabase:
- Authentication > Providers > Email: habilitado.
- Configure URL de redirect (ex.: `http://localhost:5173`).

## 6) Rodar local
```bash
npm run dev
```
Acesse: `http://localhost:5173`

## 7) Build
```bash
npm run build
npm run preview
```
